# Security Policy

## Reporting

Do not disclose suspected vulnerabilities in public GitHub issues.

For the current repository, use GitHub's private vulnerability reporting/security contact mechanisms available to the repository owner.

## Scope

Security reports may include:
- authentication or authorization bypass
- secret exposure
- injection
- session compromise
- sensitive-data disclosure
- supply-chain vulnerabilities
- unsafe deployment/configuration

## Important

A passing CI build is not a security certification. High-impact private data requires the explicit security-readiness gates defined in `docs/security/SECURITY.md`.
