# Metric couriers 0.1.0

Original synthetic mathematics authored and reviewed by Sol, continuing Luna's GyLiber foundation. Source: `docs/examples/metric-spaces-test.tex`; no private coursework or source mapping is included.

From a fresh repository checkout run `node --test math-playground/exhibits/metric-couriers/0.1.0/tests.mjs`, then `python3 -m http.server 8000 --bind 127.0.0.1 --directory math-playground/exhibits/metric-couriers/0.1.0` and open `http://127.0.0.1:8000/viewer.html`. No npm install, AI key, database, external assets or paid service is needed. The initial localhost navigation loads only these local files; the engine/renderer issue no requests.

This tests all 9 ordered pairs and 27 triples in {1,3,4}. It is not a proof of the usual metric on all real numbers. Canvas lane heights, courier speeds and faces do not define distances. There are three point selections plus Reset and optional Animate. Mathematical state is deterministic, motion starts paused and stops when hidden/disposed.

The generic formal definition is independently authored from Sol's original synthetic sample and approved for public publication within Gyile's instruction to implement ADR-0011. No private course material has been imported. The manifest records exact accepted bytes. Never edit this accepted directory after merge: use a new version, retain this one, and update the catalog.
